## 4. Social Rolodex ([SocialRolodex.tsx](../../../src/web_ui/src/components/views/SocialRolodex.tsx), [ExecutiveDossierModal.tsx](../../../src/web_ui/src/components/ui/ExecutiveDossierModal.tsx))

The contact dossier modal gets an **Edit** mode next to the existing "re-run enrichment" button (:464).

**Form fields:** Name, Company / role, Contact info, Website, Key topics (chips), Where we met.

A hint under Name and Company reads: "Changing these re-runs the web search."

**Save** calls `PUT /api/contacts/{id}`:
- **409:** inline error "Another contact is already called '<name>'" (D5).
- **`enrichment = scheduled`:**
  - the web-profile section shows a "Re-searching the web…" state, and the stale profile is hidden (the server cleared it);
  - the state ends on `contact_enriched` (profile shown) or `contact_enrich_failed` (a message: "add the company or role to help the search" for `insufficient_anchors`, "no relevant results" for `no_results`);
  - the state is tracked in `page.tsx` as `enrichingContactIds: Set<string>`, so it survives closing and reopening the modal.

**Delete** (button in the modal footer and 🗑️ on the card):
1. `GET /api/contacts/{id}/cascade` loads what goes with the contact.
2. `ConfirmDialog`: "Delete Marco Rossi? Also deletes 2 commitments and 1 routine."
3. `DELETE /api/contacts/{id}`, then close the modal and revalidate contacts, commitments and routines.

## 6. Wiring in `page.tsx`

- New handlers next to the routine ones:
  - `handleEditAction`;
  - `handleDeleteAction`;
  - `handleEditRoutine`;
  - `handleEditContact`;
  - `handleDeleteContact`;
  - `loadContactCascade`.

  Each does an optimistic update where the list is local, a toast, `markTabUpdated`, and `notifyEcho` for deletes.
- SSE switch: one case per event of [03](03_api_and_mcp.md) §4, so that changes made through MCP (Alexa+, Claude) appear live in the dashboard.
- Props: `PeaceOfMind` receives `onEditAction` / `onDeleteAction`, `DailyRoutines` receives `handleEditRoutine`, and `SocialRolodex` receives `onEditContact` / `onDeleteContact` / `loadContactCascade` / `enrichingContactIds`.
