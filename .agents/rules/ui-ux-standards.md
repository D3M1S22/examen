# UI/UX & Design System Standards
These rules apply to all frontend generation tasks.
- **Styling**: Use Tailwind CSS exclusively. Group classes logically: Layout -> Spacing -> Typography -> Visuals.
- **Accessibility (a11y)**: All interactive elements must have `aria-label` or visible text. Ensure keyboard navigability.
- **Design Tokens**: Never hardcode hex colors or arbitrary pixel values. Use Tailwind theme variables.
